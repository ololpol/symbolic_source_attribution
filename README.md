# Symbolic Source Attribution for Irish Tunes

This repository contains the code used for my Master's thesis: [THESIS LINK WHEN IT'S PUBLISHED]

## Overview

This project performs experiments on symbolic Irish tunes using **folkRNN**, based on the **Sureel approach**. The code implements techniques for source attribution analysis on traditional Irish music represented in symbolic form.

## Running the Code

To run the experiments, perform the following commands:

1. python3 -m venv .venv
2. source .venv/bin/activate
3. pip install -r requirements.txt
4. python main.py

This makes a python virtual environment and downloads all relevant packages. The code took upwards of 8 hours to run on my not very remarkable laptop, but may be able to be ran faster on a more powerful computer.
